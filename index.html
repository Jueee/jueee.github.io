Mac 开发环境实用软件汇总

发表于 2026-07-22 分类于 软件 ， MacOS

开发类

IntelliJ IDEA

Java / 多语言旗舰 IDE，对 Spring、Maven、Gradle 生态支持极好，智能补全和重构能力业界领先。

实用技巧:

  • Cmd+Shift+A 万能搜索入口，直接输入动作名称即可直达；
  • 安装 Key Promoter X 插件帮助你记忆快捷键。

Shell 配置 (~/.zshrc):

Trae CN

字节跳动推出的 AI 原生 IDE，内置智能代码补全与对话式编程能力，适合前端和全栈快速开发。

需从官网 trae.ai 下载安装，暂无 Homebrew cask。

实用技巧:

  • Cmd+I 唤起 AI 内联编辑，选中代码后直接描述需求即可让 AI 修改代码；
  • Cmd+L 打开 AI 对话面板，可针对当前文件进行多轮问答；
  • 内置预览功能，前端项目可直接在 IDE 内查看页面效果。

Sublime Text

轻量级高性能文本编辑器，启动快、扩展丰富，适合大文件浏览和零碎文本编辑。

实用技巧:

  • Cmd+P 模糊搜索文件，Cmd+D 连续选中相同单词进行批量编辑；
  • 安装 Package Control 后推荐 A File Icon、Terminus、Alignment 插件；
  • Cmd+Shift+L 将多行选中拆分为独立光标，适合批量操作。

CodeMaker Hub

网易内部 AI 编程助手客户端，集成 Claude、DeepSeek 等模型，支持终端命令行交互和代码生成。

内部工具，通过 KM / 内部分发渠道安装。

实用技巧:

  • 终端中通过 codemaker 命令启动对话；
  • 可在设置中切换不同模型以适配不同场景。

Shell 配置 (~/.zshrc):

iTerm2

macOS 最强终端替代方案，支持分屏、热键窗口、全局搜索、Shell 集成等。

实用技巧:

  • Cmd+D 垂直分屏，Cmd+Shift+D 水平分屏；
  • 安装 zsh 插件 zsh-autosuggestions 和 zsh-syntax-highlighting 提升效率；
  • 偏好设置 → Keys → Hotkey 设置全局热键（如 Option+Space）一键呼出终端。

DBeaver

开源通用数据库管理工具，支持 MySQL、PostgreSQL、Oracle、SQLite 等几乎所有主流数据库。

实用技巧:

  • 表上右键 → View Diagram 生成 ER 图；
  • Ctrl+Enter 执行当前 SQL，无需全选手动运行；
  • 设置中开启「自动补全大小写跟随库表名」可避免手动调整大小写；
  • 驱动管理器支持从 Maven 仓库自动下载 JDBC 驱动。

MySQLWorkbench

MySQL 官方可视化管理工具，适合表结构设计、查询编写和服务器运维。

实用技巧:

  • EER Diagram 做数据库建模，支持正向工程（生成建表 SQL）和逆向工程（从现有库生成 ER 图）；
  • Server Status 面板可直观查看连接数、QPS 等运行指标；
  • 查询编辑器支持多标签页，每个标签保持独立的连接上下文。

ApiPost

国产 API 协作平台，集接口调试、文档生成、Mock 服务、自动化测试于一体，类 Postman 的替代品。

从官网 apipost.cn 下载安装，暂无 Homebrew cask。

实用技巧:

  • 接口编辑页面右键 → 生成代码，支持多种语言 / 框架的请求代码一键导出；
  • 利用环境变量管理多套服务地址（开发/测试/生产），一键切换；
  • 团队协作中可直接将接口分享给成员，同步更新文档。

Podman Desktop

无守护进程的容器管理桌面端，Docker Desktop 的开源替代方案，兼容 Docker CLI。

实用技巧:

  • 初始化 podman machine 后即可运行容器，内置 Kubernetes 扩展可快速拉起本地 K8s 集群；
  • 镜像列表支持从 Docker Hub 等注册中心一键拉取；
  • 容器日志查看器内置搜索和高亮，调试体验良好。

SwitchHosts

Hosts 文件可视化切换管理工具，支持多方案一键切换、远程 Hosts 订阅。

实用技巧:

  • 为开发/测试/生产环境分别配置 Hosts 方案，菜单栏一键切换；
  • 支持远程 URL 订阅 Hosts，团队共享配置后自动同步更新；
  • 配合浏览器刷新 DNS 缓存可即时生效。

Typora

所见即所得的 Markdown 编辑器，支持 LaTeX 数学公式、Mermaid 图表、代码高亮，写作体验流畅。

实用技巧:

  • Cmd+/ 切换源码模式，方便调整 Markdown 语法细节；
  • 图片拖入后自动复制到本地目录，无需手动管理资源路径；
  • 偏好设置中开启「打字机模式」和「专注模式」提升写作沉浸感。

命令行类

nvm (Node Version Manager)

Node.js 版本管理工具，支持安装、切换多个 Node 版本，前端开发必备。

实用技巧:

  • nvm ls-remote --lts 查看所有 LTS 版本；
  • 项目根目录创建 .nvmrc 文件写入版本号，进入目录后执行 nvm use 即可自动切换；
  • nvm alias default 20 设置全局默认 Node 版本。

git

分布式版本控制系统，开发者最常用的协作工具。

实用技巧:

  • git log --oneline --graph --all 可视化分支提交历史；
  • git stash push -m "描述" 暂存未提交改动，git stash pop 恢复；
  • git rebase -i HEAD~3 交互式整理最近三次提交。

bash

Homebrew 安装的较新版本 Bash（macOS 自带版本较旧），支持更多特性。

实用技巧:

  • 安装后需在 /etc/shells 末尾添加 /opt/homebrew/bin/bash，然后执行 chsh -s /opt/homebrew/bin/bash 切换为默认 Shell；
  • 搭配 brew install bash-completion@2 获得更强补全能力；
  • 新版 Bash 对关联数组和 shopt 选项支持更完善，脚本兼容性更好。

podman

Podman 命令行工具，无守护进程的容器引擎，完全兼容 Docker CLI。

实用技巧:

  • podman machine init && podman machine start 初始化并启动虚拟机；
  • podman-compose 可替代 docker-compose 编排容器；
  • podman image prune -a 清理无用镜像释放磁盘空间。

mysql@8.4

MySQL 8.4 数据库服务端，可通过 brew 管理启停。

实用技巧:

  • brew services start mysql@8.4 设为开机自启，brew services stop mysql@8.4 停止服务；
  • 首次启动后执行 mysql_secure_installation 配置安全选项（密码强度、匿名用户等）；
  • brew services list 查看所有 brew 管理的后台服务运行状态。

Shell 配置 (~/.zshrc):

putty

经典的 SSH / Telnet / 串口命令行客户端，轻量且跨平台。

实用技巧:

  • putty -ssh user@host -P 22 快速连接远程服务器；
  • pscp 和 psftp 随 PuTTY 一起安装，分别用于 SCP 和 SFTP 文件传输；
  • 可通过 putty -load 会话名 加载已保存的会话配置。

python@3.14

Python 3.14 运行环境，brew 安装的版本与系统 Python 隔离，更安全灵活。

实用技巧:

  • python3 -m venv .venv 为每个项目创建独立虚拟环境，source .venv/bin/activate 激活；
  • pip3 install --upgrade pip 保持 pip 最新版本；
  • brew info python@3.14 查看版本详情和依赖关系。

工具类

Google Chrome

主流浏览器，开发者工具强大，插件生态丰富。

实用技巧:

  • Cmd+Option+I 打开 DevTools，Cmd+Option+J 直接跳到 Console 面板；
  • Network 面板右键 → Save all as HAR 可存档完整请求记录，方便与后端联调；
  • Chrome 多用户配置可隔离工作和个人环境，每个 Profile 独立的书签、插件和登录态。

Foxmail

腾讯出品的桌面邮件客户端，界面简洁，支持 Gmail、Exchange、IMAP 等多种协议。

从官网 foxmail.com 下载安装，暂无 Homebrew cask。

实用技巧:

  • 「联系人分组」结合「邮件模板」可批量发送定制化邮件；
  • 设置中开启「会话模式」将往来邮件聚合成对话视图，便于追踪讨论线索；
  • 支持定时发送，适合在非工作时间预设邮件。

MailMaster（网易邮箱大师）

网易出品的全平台邮件客户端，支持所有主流邮箱协议，国内邮件服务兼容性好。

从官网下载安装，暂无 Homebrew cask。

实用技巧:

  • 智能过滤功能可将通知类邮件自动归入「通知」分类，保持收件箱清爽；
  • 绑定多个邮箱后使用「统一收件箱」一站式管理所有邮件账户；
  • 内置邮件翻译，阅读外文邮件无需切换到翻译工具。

Maccy

轻量且快速的剪贴板历史管理工具，纯原生 macOS 实现，复制过的内容随时调取。

实用技巧:

  • 设置中开启「搜索模式」后弹出窗口直接打字即可搜索历史剪贴板内容；
  • 可在忽略列表中排除 1Password 等密码管理器，防止敏感信息留存；
  • 支持固定常用片段，重启后不会清除。

Rectangle

免费开源的窗口管理工具，拖拽边缘或使用快捷键实现窗口快速分屏、排列。

实用技巧:

  • Ctrl+Option+←/→ 左右半屏、Ctrl+Option+F 全屏、Ctrl+Option+C 居中窗口；
  • Ctrl+Option+U/I 分别将窗口置于左上 / 右上四分之一；
  • 偏好设置中可自定义每种布局的快捷键，支持多显示器独立配置。

BetterAndBetter（Bab）

Mac 鼠标/触控板/键盘手势增强工具，可精细定制各种手势触发的快捷操作。

从官网 better365.cn 下载安装，暂无 Homebrew cask。

实用技巧:

  • 画 ⌘ 手势映射为 Cmd+W 关闭窗口；
  • 画 L 手势触发锁屏，离开工位时快速锁定；
  • 触控板四指下滑最小化当前窗口，四指上滑恢复。

LobsterAI（有道龙虾）

有道推出的 AI 辅助工具，集成划词翻译、文本润色、AI 对话等能力。

从官网下载安装，暂无 Homebrew cask。

实用技巧:

  • 选中文本后按 Option+D 快速翻译，无需切换到浏览器；
  • 写作场景下可用 AI 润色功能优化文档表达；
  • 支持截图翻译，方便阅读论文和文档截图中的文字。

Tunnelblick

macOS 上最常用的免费开源 OpenVPN 客户端，配置文件放入后自动识别连接。

实用技巧:

  • .ovpn 配置文件直接拖入菜单栏图标即可自动导入；
  • 偏好设置中勾选「连接时最小化」让 VPN 在后台静默工作；
  • 支持多个 VPN 配置同时接入，按需切换不同网络环境。

OpenVPN Connect

OpenVPN 官方客户端，界面现代化，支持 Profile 管理和一键连接。

实用技巧:

  • 支持通过 URL 导入 Profile，团队共享 VPN 配置时一键添加；
  • 连接日志面板可实时查看握手过程和错误详情，便于排查问题；
  • 与 Tunnelblick 按需互补：前者适合标准场景，后者更适合复杂多配置环境。

AppCleaner

轻量级应用卸载工具，拖拽目标软件即可扫描关联文件并彻底清理，比系统自带卸载更干净。

从官网 freemacsoft.net/appcleaner 下载安装，暂无 Homebrew cask。

实用技巧:

  • 将需要卸载的应用拖入 AppCleaner 窗口，会自动扫描关联的配置文件、缓存、日志等残留文件；
  • 勾选 SmartDelete 自动监测：当将应用拖入废纸篓时自动弹出清理提示，无需手动启动 AppCleaner；
  • 列表视图可查看所有应用及其占用空间，方便批量清理不常用软件。

权限问题：首次运行时若提示 "没权限"，按以下步骤授权：

  1. 打开 系统设置 → 隐私与安全性 → 完全磁盘访问权限；
  2. 点击 + 添加 /Applications/AppCleaner.app，开启开关；
  3. 如扫描某些 App 仍无结果，还需要在 辅助功能（Accessibility）中同样添加 AppCleaner；
  4. 重新启动 AppCleaner 即可正常使用。

Hidden Bar

菜单栏图标管理工具，可将不常用的菜单栏图标折叠隐藏，保持菜单栏整洁。

实用技巧:

  • 安装后在菜单栏会出现 ∣ 和 > 两个分隔符图标，按住 Cmd 拖拽图标可自由排列位置；
  • 拖到 ∣ 左侧的图标始终显示（常用），拖到 ∣ 和 > 之间的图标默认隐藏，点击 > 可展开查看；
  • 偏好设置中勾选「自动隐藏」可设置延时，鼠标移开后自动收起，省去手动操作。
